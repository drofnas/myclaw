# TOOLS.md - Local Notes

Skills define _how_ tools work. This file is for _your_ specifics — the stuff unique to this setup.

## What Goes Here

- Issue tracker details (URLs, project IDs, label names)
- Repo locations and how to browse them
- Any CLI tools used to create/update issues
- Templates or saved formats in use

## Examples

```markdown
### Issue Tracker
- Platform: GitHub Issues
- Repo: github.com/user/project
- Labels: feature, fix, refactor, chore, docs, blocked
- Milestone format: vYYYY.M.D

### Repos
- main → ~/Projects/myproject (TypeScript, pnpm)

### CLI
- gh issue create --repo user/project --title "..." --body-file issue.md --label feature
```
